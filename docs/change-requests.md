## CR-004 — Website content and pricing aligned with the Tiffin Box app (Proposed)
- **Requested by:** Engineering Lead, working session 2026-11-23, with the document "Tiffin Box Website — Full Spec to Match the App" (dated 23 Nov 2026, 10 pages). The document says it replaces the original Business & Website Brief. The PDF is not filed in this repo yet (the repo is currently public; file it in `intake/client/` once it is private again).
- **Change (public site):** new pricing rule (plan meal = old price + Rs 50 service + Rs 150 delivery; cheapest meal Rs 500); a fifth plan, Starter (3 days, Rs 4,800), shown first; plan tags (New, Cheapest, Most popular); Student shown as a range (Rs 750–800); late-night meal (11 PM–1 AM, Rs 900 a night); breakfast add-on Rs 550 a day; "Who's eating?" section (just me, family or group, guests); Rs 150 delivery on custom orders with a worked example; delivery table with late-night, family and guest rows; two more "Who we serve" cards; FAQ grows from 7 to 12; Instagram QR in the footer; Urdu name; draft notes and question tags removed from public pages.
- **Explicitly out:** live customer location; any free first meal.
- **Conflicts with the approved PRD:** FR-07 required ONE confirmed Student price before publishing; the new document keeps a range. The Starter plan is not a weekly plan, so "weekly price" no longer fits every plan. Family/group and guest orders, and late-night meals, are not modelled in subscriptions or payments (FR-24..30): this CR changes what the site SAYS, not how the admin records such orders.
- **Still needed from the client (per the document):** WhatsApp number, order hours, business name and address, delivery boundary, the story, real food photos, the logo file.
- **Impact:** one migration (plan tag, price range, period label; delivery and late-night prices in pricing rules), a content update script for the draft tables, the content layer, all six public pages, footer, tests. Admin screens for the new plan fields are NOT part of this change.
- **Status:** in progress on `stage3/backend`; needs CEO acceptance with the Stage 3 milestone.
- **CR-004 addendum (2026-11-24):** the Engineering Lead supplied "Tiffin Box Lahore.md", a text export of the app-side website design. It keeps the same prices and rules and changes wording on every page (shorter "Who we serve" cards, "11 PM to 1 AM" phrasing, delivery table labels, About without a story section, footer "Scan to follow"). It also shows two interactive pieces: a people counter under "Who's eating?" with an Order on WhatsApp button, and a dish + add-ons builder on Customize with a running total and an Order on WhatsApp button. The export is one long page with anchor links; the six separate pages are kept, as the spec of 23 Nov requires. Order hours "9 AM to 9 PM" in the export are marked there as sample values and are not applied.
- **CR-004 addendum 2 (2026-11-24):** the Engineering Lead supplied the design itself ("Tiffin Box Lahore.zip": one HTML file and the logo) and asked for the public site to match it exactly. This is a visual redesign of the public pages on top of the content changes: new component styles, light and dark colour schemes, a drawn hero illustration as the default hero, day tabs on the Menu page, plan cards with a "Choose" button, the three-option "Who's eating?" panel, the Customize builder with add-on toggles, a scrolling navigation row on phones instead of a menu button, and the supplied Urdu badge as the default logo. The six routes, the data model and the admin are unchanged. It supersedes the approved Stage 1 design for the public pages, so it needs CEO acceptance with the Stage 3 milestone.
- **CR-004 addendum 3 (2026-11-24), decisions by the Engineering Lead in the working session:** (1) the public site becomes ONE page with the design's section navigation (`/#menu`, `/#plans`, ...); the old page addresses redirect. Consequence accepted: search engines see one page with one title instead of six (weakens NFR-04's per-page titles and the FR-01 "six pages" wording). (2) The header logo and the home illustration always come from the design; a logo or home photo assigned in the admin (CR-003) no longer changes the public site. (3) Prices, plans, menu, dishes, add-ons and FAQ stay admin-managed. (4) The WhatsApp number and order hours stay settings-driven; the design's sample values are not used.

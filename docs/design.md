## How to view
Clone the repo and open `design/prototype/index.html` in a browser (needs internet for Google Fonts), or serve the `design/` folder with any static server. There is no hosted preview link, no Figma file and no Claude Design artifact for this stage.

## What the prototype is not
Static HTML and CSS with sample data. No application code, no login, no database. WhatsApp buttons open a prototype note. Logo, photos, WhatsApp number, order hours and website are labelled placeholders.
